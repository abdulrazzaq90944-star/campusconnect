# Campusly — College Event Management Website

A responsive, single-page college events website built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Included

- Responsive campus events landing page
- Event cards with category filters and live search
- Save buttons and registration dialog
- Organizer contact interaction
- Accessible labels, keyboard dismissal, and mobile layout

## Publish with GitHub Pages

1. Create a GitHub repository and add `index.html` at its root.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will show the published site URL in the Pages settings.

The event data and campus details are demo content. The registration form currently provides an on-page confirmation and does not store or send submissions; connect it to a backend or form service before using it for real registrations.
